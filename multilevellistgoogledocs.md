# How to Create a Multilevel Heading List in Google Docs

Product documentation often needs numbered headings such as 1.0, 1.1, and 1.3.1, so readers can find sections and refer to them by number. Google Docs has no built-in setting that links heading styles to numbering the way some other word processors do. You can still get the same result with the numbered list feature and two keys: **Tab** and **Shift+Tab**.

This article shows how to build a numbered heading structure from 1.0 through 5.0 in Google Docs.

## Before You Begin

Keep these points in mind:

- **Heading styles and numbering are separate settings.** The list level controls the number. The heading style (Heading 1, Heading 2, and so on) controls the look. You set both on each line.
- **Enter** creates a new line at the same level as the current line.
- **Tab** moves the current line one level deeper (for example, from 1.3 to 1.3.1).
- **Shift+Tab** moves the current line one level up (for example, from 1.3.1 to 1.4).
- **Do not use Backspace** to change levels. Backspace removes the line from the list, and the numbering breaks.

## Create the First Heading (1.0)

1. Open a Google Doc.
2. Type your first heading text, for example, `Introduction`.
3. Apply **Heading 1** to the line from the styles dropdown, or press **Ctrl+Alt+1** (**Cmd+Option+1** on Mac).
4. With the cursor in the line, click the **Numbered list** button in the toolbar.
5. Select the multilevel option that shows the 1., 1.1, 1.1.1 pattern.

The line now shows the first-level number, for example, **1.0**. The exact display (1. or 1.0) depends on the list style you select.

## Create the Second-Level Headings (1.1, 1.2, 1.3)

1. Place the cursor at the end of the **1.0** heading and press **Enter**. The new line shows **2.0**.
2. Press **Tab**. The number changes to **1.1**.
3. Apply **Heading 2** to the line and type the heading text.
4. Press **Enter**. The new line shows **1.2**. Type the heading text.
5. Press **Enter** again. The new line shows **1.3**. Type the heading text.

## Create the Third-Level Headings (1.3.1, 1.3.2, 1.3.3, 1.3.4)

1. At the end of the **1.3** heading, press **Enter**. The new line shows **1.4**.
2. Press **Tab**. The number changes to **1.3.1**.
3. Apply **Heading 3** to the line and type the heading text.
4. Press **Enter**. The new line shows **1.3.2**. Type the heading text.
5. Press **Enter** to create **1.3.3**, and press **Enter** again to create **1.3.4**.

## Return to the Top Level (2.0)

Now you want to start the next main section.

1. At the end of **1.3.4**, press **Enter**. The new line shows **1.3.5**.
2. Press **Shift+Tab**. The number changes to **1.4**. This is a passing state, so do not type anything yet.
3. Press **Shift+Tab** again. The number changes to **2.0**.
4. Apply **Heading 1** to the line and type the heading text.

## Continue with 3.0, 4.0, and 5.0

Repeat the same pattern for each new main section:

1. To add another main heading at the same level as **2.0**, place the cursor at the end of the **2.0** line and press **Enter**. The new line shows **3.0**. Apply **Heading 1** and type the text.
2. To add subheadings under a main heading, press **Enter** and then **Tab** to go to 3.1. Press **Tab** again to go to 3.1.1.
3. To go back up, press **Shift+Tab** one level at a time until you reach the number you want, for example, **4.0**.
4. Repeat for **5.0**.

## Match Heading Styles to List Levels

Pressing Tab or Shift+Tab changes only the number. After you set the level, check that the heading style matches:

| Number format | Heading style |
|---|---|
| 1.0, 2.0, 3.0 | Heading 1 |
| 1.1, 1.2, 1.3 | Heading 2 |
| 1.3.1, 1.3.2 | Heading 3 |
| 1.3.1.1 | Heading 4 |

You can apply a style from the styles dropdown or with **Ctrl+Alt+1** to **Ctrl+Alt+4** (**Cmd+Option+1** to **Cmd+Option+4** on Mac).

## Add Body Text Under a Heading

1. Click at the end of a heading line and press **Enter**.
2. Click the **Numbered list** button to turn off numbering for the new line.
3. Change the style to **Normal text** and type your content.
4. To add the next heading, click at the end of the previous heading line (not the body text) and press **Enter**. Then use **Tab** or **Shift+Tab** to set the level.

If the numbering restarts at 1 after body text, right-click the number and choose **Continue previous numbering**.

## Troubleshooting

| Problem | Solution |
|---|---|
| Pressing Enter gives 2.0 instead of 1.1 | Press **Tab** to move the line one level deeper. |
| Numbering shows an unexpected value such as 1.3.4.6 | Click the line and press **Shift+Tab** until it reaches the correct level. Avoid Backspace. |
| Numbers restart at 1 | Right-click the number and choose **Continue previous numbering**. |
| Number is correct but the text looks wrong | Apply the matching heading style to the line. |

## Conclusion

A numbered heading structure makes product documentation easier to navigate, review, and reference in feedback from engineers and product managers. This article gives new technical writers a repeatable method: use Enter to continue at the same level, Tab to go deeper, and Shift+Tab to go back up. Knowing how heading styles and numbering work as separate settings helps you avoid the most common formatting mistakes. With this approach, you can build clear, consistently numbered documents in Google Docs from your first project.
